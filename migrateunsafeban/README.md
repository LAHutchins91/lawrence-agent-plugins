# Migrate Unsafe Ban

Fail CI on DROP TABLE/COLUMN, TRUNCATE, DELETE without WHERE in migrations.

## What it catches

Fail CI on DROP TABLE/COLUMN, TRUNCATE, DELETE without WHERE in migrations — surfaced as editor guidance so you can fix issues before they merge.

## Who it's for

Security-minded teams who want issues caught in the editor before CI.
