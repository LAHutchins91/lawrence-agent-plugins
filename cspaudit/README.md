# CspAudit

Lint Content-Security-Policy for unsafe-inline / unsafe-eval / wildcards — catch `'unsafe-inline'`, `'unsafe-eval'`, host `*`, and scheme wildcards (`https:`, `data:`) in headers, HTML meta, nginx, Next, and JSON.

## What it catches
