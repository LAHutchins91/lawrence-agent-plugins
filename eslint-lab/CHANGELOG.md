# Changelog

All notable changes to **eslint-lab** are documented here.

## 1.0.0 — 2026-09-13

- Add `eslint_rules_list` for ESLint rule ids/severities in pasted `.eslintrc*` / `eslint.config.*` text.
- Add `eslint_extends_hint` for `extends`, `plugin:`, `eslint:recommended`, `airbnb`, and `next` counts.
- Add `eslint_overrides_hint` for `overrides`, `files:`, `parserOptions`, `env`, `plugins`, and `ignorePatterns`.
- Add `eslint_lint_lite` for rule_off_all, missing_extends, empty_file, override_without_files, and conflicting_semi_quotes_hint findings.
- Add two skills, smoke tests, bundled stdio MCP packaging, and local Cursor plugin distribution. Local pasted source only; no network and no eslint CLI. FREE MIT.
