# Changelog

## 1.0.0 — 2026-09-13

- Initial release of **terraform-lab** MCP server.
- Tools: `terraform_blocks_list`, `terraform_providers_hint`, `terraform_modules_hint`, `terraform_lint_lite`.
- Skills: `terraform-blocks-providers`, `terraform-modules-lint`.
- Pure Terraform HCL string heuristics — no terraform CLI, plan/apply, or network.
- Marketplace packaging under `plugin-dist/` (MIT, developer-tools, FREE).
- Distinct from terraform-cdk-lab (CDKTF) and terraform-hcl-lab (different tool set).
