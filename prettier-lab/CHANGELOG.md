# Changelog

All notable changes to **prettier-lab** are documented here.

## 1.0.0 — 2026-09-13

- Add `prettier_options_list` for Prettier option keys/values in pasted `.prettierrc` / `prettier.config.*` text.
- Add `prettier_overrides_hint` for `overrides`, nested `files:`, and nested `options:` counts.
- Add `prettier_ignores_hint` for `.prettierignore`, `prettier-ignore`, `# prettier-ignore`, and `ignorePath`.
- Add `prettier_lint_lite` for conflicting_quotes, print_width_extreme, empty_file, tabs_and_spaces_mixed_hint, and override_without_files findings.
- Add two skills, smoke tests, bundled stdio MCP packaging, and local Cursor plugin distribution. Local pasted source only; no network and no prettier CLI. FREE MIT.
