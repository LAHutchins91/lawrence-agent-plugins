# Changelog

All notable changes to **stylelint-lab** are documented here.

## 1.0.0 — 2026-09-13

- Add `stylelint_rules_list` for Stylelint rule ids/severities in pasted `.stylelintrc*` / `stylelint.config.*` text.
- Add `stylelint_extends_hint` for `extends`, `stylelint-config-`, `standard`, `prettier`, and `recommended` counts.
- Add `stylelint_overrides_hint` for `overrides`, `files:`, `customSyntax`, `plugins`, `ignoreFiles`, and `defaultSeverity`.
- Add `stylelint_lint_lite` for rule_null_many, missing_extends, empty_file, override_without_files, and conflicting_prettier_extends findings.
- Add two skills, smoke tests, bundled stdio MCP packaging, and local Cursor plugin distribution. Local pasted source only; no network and no stylelint CLI. FREE MIT.
