# Changelog

All notable changes to **markdownlint-lab** are documented here.

## 1.0.0 — 2026-09-13

- Add `markdownlint_rules_list` for unique `MD###` rule IDs in pasted config/comments.
- Add `markdownlint_extends_hint` for quoted `extends` keys, `markdownlint-config-` packages, and `extends:` keys.
- Add `markdownlint_ignores_hint` for `ignores`, `ignore:`, `markdownlint-disable`, `markdownlint-disable-line`, and `markdownlint-disable-next-line`.
- Add `markdownlint_lint_lite` for missing_h1, trailing_spaces, empty_file, broad_disable, and long_line_heuristic findings.
- Add two skills, smoke tests, bundled stdio MCP packaging, and local Cursor plugin distribution. Local pasted source only; no network and no markdownlint CLI. FREE MIT.
